# Google Form orders — sample export

Use `sample-orders.csv` to try the import flow:

1. Open **Google Form orders** → **New event** (name, location, date, start/end time).
2. Open the event → upload this CSV (or your Google Forms CSV/XLSX export).
3. Upload again after changing a row — existing responses update; new ones are added.
4. Send WhatsApp confirmations one-by-one or to all.

Expected columns (aliases work too): Timestamp, Name, Email, Phone, Order, Guests.
